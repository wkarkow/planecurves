Sine Oval

A parametric oval obtained by nesting the sine function a variable number of times in the y-coordinate of an ellipse, then rescaling so that the entered height remains the actual maximum.

Sine Oval parametric equations:
\[ x = a\cos t,\quad y = b\cdot\dfrac{\operatorname{nest\_sin}(t,n)}{\operatorname{nest\_sin}(\pi/2,n)} \]
Nested sine:
\[ \operatorname{nest\_sin}(t,n) = \underbrace{\sin(\sin(\cdots\sin(t)\cdots))}_{n\text{ times}} \]

History and Applications

There are alternate means of interpolation between a circle and a square. See Squircle and Rectellipse for the two algebraic methods that differ from the method used here. The Squircle and Rectellipse pages each present the same pair of equations: the superellipse with exponent fixed at 4, and the Fernández-Guasti quartic that employs a squareness parameter \(s\) running from 0 (circle or ellipse) to 1 (square or rectangle). The nested-sine construction on this page is a third, non-algebraic route. It is obtained by nesting the sine function a variable number of times in the \(y\)-coordinate of a parametric ellipse, then rescaling so that the entered value of \(b\) remains the actual maximum height. The form was presented by Kenneth E. Caviness in the 2011 Wolfram Demonstration “Sine Oval and Nested Trig Functions.” With nest count \(n=1\) the curve is an ordinary ellipse (or circle if \(a=b\)); larger \(n\) produces a progressively squarer outline while the sides remain smooth. No engineering applications specific to the nested-sine oval were identified.

References

  1. https://demonstrations.wolfram.com/SineOvalAndNestedTrigFunctions/ (Sine oval equations, Kenneth E. Caviness, 2011, Wolfram Demonstrations Project)

AutoLISP Code

(defun C:SINEOVAL (/ basept xaxisangle cd sa sb sm om os divcount cosangle sinangle x0 y0 plineents segcount baseinfo paramstep
                     divpt restartflag id iq dcl opt kw mode dpr dct dpt span eq_display xc yc skm a1 a2 x1 y1 x2 y2 fa fb fc fd)
  (defun nest_sin (a b / c d)
    (setq d a c 0)
    (repeat b (setq d (sin d) c (1+ c))) d)
  (setq id "Sine Oval"
        iq "x=a cos(t), y=b nest_sin(t,n)"
        dcl nil
        opt nil
        kw 0
        mode 'polar
        dpr "# of divisions for full curve"
        dct 360
        dpt nil
        span 360
        kw (ca id iq dcl opt kw mode dpr dct dpt span))
  (princ "\nx=a cos(t), y=b nest_sin(t,n)")
  (setq fa (get_real 2 "a (x semi-axis)" 1.0)
        fb (get_real 2 "b (y scale, y_max)" 1.0)
        fc (get_integer 6 "n (nest count, n ≥ 1)" 2)
        fd (/ fb (nest_sin (/ pi 2.0) fc))
        eq_display (strcat "\na=" (rtos fa 2 4) ", b=" (rtos fb 2 4) ", n=" (itoa fc) "  (y scaled by " (rtos (/ fd fb) 2 4) ")")
        xc '(* fa (cos (eval a2)))
        yc '(* fd (nest_sin (eval a2) fc))
        skm '(T T T)
        a1 0
        a2 a1
        x1 (eval xc)
        y1 (eval yc)
        a2 '(+ a1 paramstep)
        x2 '(eval xc)
        y2 '(eval yc))
  (cc))
(C:SINEOVAL)
