Cotangent Curve

A periodic trigonometric curve with vertical asymptotes spaced π/b apart.

Generalized Cotangent Cartesian equation:
\[ y = a \cdot \cot(b x - c) \]

History and Applications

The cotangent function1 is one of the six classical trigonometric ratios. Its systematic tabulation began in the golden Islamic Age with Habash al-Hasib al-Marwazi around 830 AD2 , who included both tangent and cotangent values in astronomical tables. The term “cotangens” entered European mathematics in 1620 when Edmund Gunter published tables of the function in his Canon triangulorum3 . Leonhard Euler later incorporated it fully into analytic trigonometry in the 18th century.1 The cotangent graph consists of repeating branches separated by vertical asymptotes spaced π/b apart. The parameter a controls vertical scaling of each branch, b sets the horizontal compression or expansion of the period, and c produces a horizontal phase shift. Engineers and draftsmen recognize this shape immediately as a periodic function with sharp discontinuities at the asymptotes, which is useful when modeling phenomena that exhibit rapid transitions or infinite slopes.

In engineering and the natural sciences the cotangent function appears wherever angular ratios must be inverted or where complementary-angle relationships simplify calculations. Surveyors and civil engineers apply cotangent to compute heights of structures or distances across inaccessible terrain from measured elevation angles. In mechanical engineering it arises in solutions for certain beam-vibration modes and resonance problems. Electrical engineers encounter cotangent terms in the analysis of alternating-current circuits and transmission-line impedance models. Astronomers use cotangent relations in spherical trigonometry for coordinate transformations between equatorial and horizon systems. Because cotangent rises so fast near asymptotes, be sure to specify enough divisions to the division point to capture high enough y values as desired. Setting maximum x and y values allowed will clip extremes but if set too low will also shorten pline lengths shorter than desired depending on the number of divisions. For very y values, a boundary line and the Trim command will often be required. If one sees connections across asymptotes, redo the curve with a greater number of divisions within spans.

AutoLISP Code

(defun C:COTANGENT (/ basept xaxisangle cd sa sb sm om os divcount cosangle sinangle x0 y0 plineents segcount baseinfo divpt xspan paramstep
                    restartflag id iq dcl opt kw mode dpr dct dpt span eq_display xc yc skm a1 a2 x1 y1 x2 y2 maxdraw fa fb fc fd fe ff fg fh p1 p2)
  (setq id "Cotangent Curve"
        iq "y=a·cot(b·x-c)"
        dcl "COTANGENT"
        opt '("a,b values" "Zero pt, a value" "Asymptote, a,b values" "Asymptote pt, zero pt" "Phase shift, a value" "a value, 1 pt on curve"
              "Asymptote point, 1 pt on curve" "Zero pt, 1 pt on curve" "Wavelength, 1pt on curve")
        kw 0
        mode 'param
        dpr "# of divisions to division point"
        dct 100
        dpt '(1.0 0.0)
        span nil
        kw (ca id iq dcl opt kw mode dpr dct dpt span))
  (cond
   ((eq kw 0)
    (setq fa (get_real 2 "a (vertical scaling)" 1.0)
          fb (get_real 2 "b (angle multiplier)" 1.0)
          fd (get_keyword 0 "Yes No" "Divide period by π? (if not, period = b*π )" "Yes")
          fb (if (eq fd "Yes") (* fb pi) 1.0)
          fc 0.0))
   ((eq kw 1)
    (setq fa (get_real 2 "a (vertical scaling)" 1.0)
          p1 (get_point 0 "Zero point" divpt basept)
          fd (get_xspan basept xaxisangle p1)
          fb (/ pi (* 2 fd))
          fc 0.0)) 
   ((eq kw 2)
    (setq p1 (get_point 0 "Point on asymptote" divpt basept)
          fa (get_real 2 "a (vertical scaling)" 1.0)
          fb (get_real 2 "b (angle multiplier)" 1.0)
          fd (get_xspan basept xaxisangle p1)
          fc (* fb fd)))
   ((eq kw 3)
    (setq p1 (get_point 0 "Point on asymptote" divpt basept)
          p2 (get_point 0 "Zero point" divpt basept)
          fa (get_real 2 "a (vertical scaling)" 1.0)
          fd (get_xspan basept xaxisangle p1)
          fc (get_xspan basept xaxisangle p2)
          fb (/ pi (* 2 (abs (- fc fd))))
          fc (* fb fd)))
   ((eq kw 4)
    (setq fa (get_real 2 "a (vertical scaling)" 1.0)
          fb (get_real 2 "b (angle multiplier)" 1.0)
          fc (* (get_real 2 "phase shift in degrees" 0.0) (/ pi 180))))
   ((eq kw 5)
    (setq p1 (get_point 0 "Curve point off x axis" divpt basept)
         fa (get_real 2 "a (vertical scaling)" 1.0)
         fd (get_xspan basept xaxisangle p1)
         fb (get_yspan basept xaxisangle p1)
         fc 0.0
         fe (atan (/ fa (avoid_zero fb)))
         fe (if (< fb 0.0) (+ pi fe) fe)
         fb (/ fe fd)))
   ((eq kw 6)
    (setq p1 (get_point 0 "Point on asymptote" divpt basept)
          p2 (get_point 0 "Curve point off x axis" divpt basept)
          fd (get_xspan basept xaxisangle p1)
          fe (get_xspan basept xaxisangle p2)
          ff (get_yspan basept xaxisangle p2)
          fa (get_real 2 "a (vertical scaling)" 1.0)
          fg (avoid_zero (- fe fd))
          fh (atan (/ fa (avoid_zero ff)))
          fb (/ fh fg)
          fb (if (and (< fb 0.0) (> ff 0.0)) (/ (- fh pi) fg) fb)
          fb (if (and (< fb 0.0) (< ff 0.0)) (/ (+ fh pi) fg) fb)
          fc (* fb fd)))
   ((eq kw 7)
    (setq p1 (get_point 0 "Zero point" divpt basept)
          p2 (get_point 0 "Curve point off x axis" divpt basept)
          fa (get_real 2 "a (vertical scaling)" 1.0)
          fd (get_xspan basept xaxisangle p1)
          fe (get_xspan basept xaxisangle p2)
          ff (get_yspan basept xaxisangle p2)
          fg (avoid_zero (- fe fd))
          fh (atan (/ (- ff) (avoid_zero fa)))
          fb (/ fh (avoid_zero fg))
          fb (if (and (< fb 0.0) (< ff 0.0)) (/ (- fh pi) (avoid_zero fg)) fb)
          fb (if (and (< fb 0.0) (> ff 0.0)) (/ (+ fh pi) (avoid_zero fg)) fb)
          fc (- (* fb fd) (/ pi 2))))
   ((eq kw 8)
    (setq p1 (get_point 0 "Curve point off x axis" divpt basept)
          fd (get_real 2 "wavelength between zero crossings, will flip curve depending on curve pt" pi)
          fe (get_xspan basept xaxisangle p1)
          ff (get_yspan basept xaxisangle p1)
          fb (/ pi (avoid_zero fd))
          fa (* ff (tan (* fb fe)))
          fc 0.0)))
  (setq eq_display (strcat "\nY=" (rtos fa 2 4) "·cot(" (rtos fb 2 4) "·x-" (rtos fc 2 4) ")")
        maxdraw (get_real 2 "Maximum x and y values allowed?" 1000)
        paramstep (/ xspan divcount)
        xc '(eval a2)
        yc '(* fa (cot (- (* fb (eval a2)) fc)))
        skm '(T T nil)
        a1 0
        a2 a1
        x1 (eval xc)
        y1 (eval yc)
        a2 '(+ a1 paramstep)
        x2 '(eval xc)
        y2 '(eval yc))
  (cc))
