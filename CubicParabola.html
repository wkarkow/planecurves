Cubic Parabola

A cubic polynomial curve with an inflection point, with symmetric and triple-root variants.

Symmetric Cubic Parabola Cartesian equation:
\[ y = \dfrac{x^{3} + b x}{a^{2}} \]
Triple Root Cubic Parabola Cartesian equation:
\[ y = a (x - b)^{3} \]

History and Applications

The cubical parabola, also known as the cubic parabolas, is the graph of a cubic polynomial. These curves were studied by Isaac Newton and Gottfried Wilhelm Leibniz as early as 16751. The presence of an inflection point, where the curvature changes sign smoothly, makes the cubic parabola particularly useful in engineering. The Symmetric variant includes a linear term to adjust the initial slope while preserving odd symmetry. The Triple Root variant centers the inflection point at a chosen x-value.

Real-life applications center on transportation infrastructure. Cubic parabolas have been employed in railway alignment design since the mid-19th century and remain in use today for transition spirals in many railway systems2. In railway and highway design, the cubic parabola serves as a transition curve between straight sections and circular curves2,3. Known in some contexts as the Nördling parabola, it provides a gradual change in curvature. This gradual change reduces lateral jerk, improving passenger comfort and reducing wear on tracks and vehicles. The curve is popular because offsets from the tangent can be calculated easily as they vary with the cube of the distance along the curve.

AutoLISP Code

(defun C:CUBICPARABOLA (/ basept xaxisangle cd sa sb sm om os divcount cosangle sinangle x0 y0 plineents segcount baseinfo paramstep divpt
                          xspan restartflag id iq dcl opt kw mode dpr dct dpt span eq_display xc yc skm a1 a2 x1 y1 x2 y2 fa fb fc shiftx shifty)
  (setq id "Cubic Parabola"
        iq ""
        dcl "CUBICPARABOLA"
        opt '("Symmetric" "Triple Root")
        kw 0
        mode 'param
        dpr "# of divisions to x-span of division point"
        dct 200
        dpt '(2.0 0.0)
        span nil
        kw (ca id iq dcl opt kw mode dpr dct dpt span))
  (cond
    ((eq kw 0)
     (princ "\ny=(x³+b·x)/a²")
     (setq fa (get_real 2 "a (vertical scale factor)" 1.0)
           fb (get_real 0 "b (initial slope)" 0.0)
           eq_display (strcat "\na=" (rtos fa 2 4) ", b=" (rtos fb 2 4))
           xc '(eval a2)
           yc '(/ (+ (alt_expt (eval a2) 3 nil) (* fb (eval a2))) (alt_expt fa 2 nil))))
    ((eq kw 1)
     (princ "\ny=a·(x-b)³")
     (setq fa (get_real 2 "a (vertical scale factor)" 1.0)
           fb (get_real 0 "b (inflection point x value)" 0.0)
           eq_display (strcat "\na=" (rtos fa 2 4) ", b=" (rtos fb 2 4))
           xc '(eval a2)
           yc '(* fa (alt_expt (eval a2) 3 nil))
           x0 (+ x0 (* fb cosangle))
           y0 (+ y0 (* fb sinangle)))))
  (setq paramstep (/ xspan divcount)
        skm '(T T nil)
        a1 0
        a2 a1
        x1 (eval xc)
        y1 (eval yc)
        a2 '(+ a1 paramstep)
        x2 '(eval xc)
        y2 '(eval yc))
  (cc))
(C:CUBICPARABOLA)
