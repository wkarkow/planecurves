Caveats

Important notes about how curves are generated and displayed in AutoCAD.

  1. To avoid errors created by settings such as SNAP, ORTHO, and OSNAP, their variables are stored, temporarily cancelled, then restored during the execution of a curve.
  2. To avoid division by zero, whenever denominators are less than 10-12 (1e-12 in AutoLISP), the denominators for those point calculations are changed to 1e-12. The AutoLISP code for denominator input is: (defun avoid_zero (input) (if (< (abs input) 1e-13) 1e-12 input))
  3. To avoid imaginary numbers, the (expt number power) function is modified to ALT_EXPT that converts various domain situations and imaginary values so that only real values within 1e7 are plotted. A setting, complexsafe, either nil or T, allows one to either flip an imaginary root to an artificial real value or suppress it entirely. Both code and details of this and other utility functions are kept in Curvecore.lsp. See For AutoCAD Users
  4. Therefore, any curve whose formula contains the possibility of division by zero or imaginary numbers may have an altered appearance, as the polyline may include points with these ‘corrections’. Search the code for the functions (avoid_zero... and (alt_expt... to identify the suspects.
  5. For the above reasons, extraneous lines to and from infinity have been removed in the images that follow.
  6. The curves, their variable values, and their image magnifications are arbitrarily chosen to reveal interesting portions.
  7. Where curves are commonly used and known but defy parametric calculation, parametric approximations found in the literature are used so that the user can still plot these, although with varying accuracy. An example is the Bessel function.
