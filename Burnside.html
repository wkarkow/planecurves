Burnside Curve

A quintic algebraic curve with a closed oval and an open, diverging bell.

Burnside Curve implicit equation:
\[ y^{2} - x(x^{4} - 1) = 0 \]
Burnside Curve Cartesian equation:
\[ y = ±\sqrt{x(x^{4} - 1)} \]

History and Applications

The Burnside curve is a plane algebraic curve studied in the late nineteenth century in the context of complex analysis and algebraic geometry. It is attributed to British mathematician William Burnside (1852–1927), who investigated it in 1893 while examining examples of algebraic curves whose associated Riemann surfaces have higher genus yet admit explicit analytic descriptions. It is a quintic curve whose area uses the Gamma function and can be parametrized via the Weierstrass elliptic function.1 The curve is defined implicitly by y² − x(x⁴ − 1) = 0. It is notable for combining a compact real component with a separate unbounded branch, separated by an interval in which the curve has no real points. On the interval [−1,0] it forms a closed oval symmetric about the x-axis. On the interval [0,1] the defining polynomial is negative and the curve exists only in the complex plane. For x ≥ 1, the curve re-enters the real plane and produces an open, rapidly diverging branch whose profile resembles a bell or hyperbola-like flare.1 Subsequent research by Y. V. Brezhnev has examined the uniformization of the curve, linking Burnside’s parametrization to Schwarz’s differential equation and Fuchsian equations.2

The Burnside curve has no direct applications in engineering or the natural sciences.

AutoLISP Code

(defun C:BURNSIDE (/ basept xaxisangle cd sa sb sm om os divcount cosangle sinangle x0 y0 plineents segcount baseinfo paramstep divpt xspan restartflag
                   id iq dcl opt kw mode dpr dct dpt span eq_display xc yc skm a1 a2 x1 y1 x2 y2 maxdraw)
  (setq id "Burnside Curve"
        iq "y²-x(x⁴-1)=0"
        dcl "BURNSIDE"
        opt '("Oval" "Bell")
        kw 0
        mode 'param
        dpr "# of divisions to division point"
        dct 100
        dpt nil
        span nil
        kw (ca id iq dcl opt kw mode dpr dct dpt span))
  (if (= kw 0)
    (setq a1 -1.0
          span 1.0
          eq_display "\nOval branch: x = -1 to 0")
    (setq divpt (get_boundpt "Bell end point (x > 1)" "5,0" '(5.0 0.0) basept 1.0 nil T nil nil nil)
          xspan (get_xspan basept xaxisangle divpt)
          a1 1.0
          span (- xspan 1.0)
          eq_display (strcat "\nBell branch: x = 1 to " (rtos xspan 2 4))))
  (setq xc '(eval a2)
        yc '(if (<= (* (eval a2) (- (expt (eval a2) 4) 1.0)) 1e-9) 0.0 (alt_expt (max (* (eval a2) (- (expt (eval a2) 4) 1.0)) 0.0) 0.5 nil))
        paramstep (/ span divcount)
        skm '(T nil T)
        a2 a1
        x1 (eval xc)
        y1 (eval yc)
        a2 '(+ a1 paramstep)
        x2 '(eval xc)
        y2 '(eval yc))
  (cc))
