Bowditch Curve

Parametric curve traced by a point undergoing two perpendicular simple harmonic motions.

Bowditch Curve parametric equations:
\[ x = A \sin(at + \delta),\quad y = B \sin(bt) \]
Generalized parametric equations:
\[ x = a \sin(bt + c),\quad y = d \sin(et + f) + g \left[\sin(ht + i)\right]^{j} \]

History and Applications

The Bowditch curve, also known as the Lissajous curve or Lissajous figure1,2, describes the path of a point subject to two perpendicular simple harmonic motions. Nathaniel Bowditch (1773–1838), the American mathematician, astronomer and navigator best known for The New American Practical Navigator, first investigated these curves in 1815. French physicist Jules Antoine Lissajous (1822–1880) later studied them in greater detail in 1857, developing mechanical optical devices using tuning forks to produce and observe the figures experimentally.

In engineering, the most practical use occurs in oscilloscopes. One sinusoidal signal controls horizontal deflection while a second controls vertical deflection. The resulting closed curve immediately indicates the frequency ratio (from the number of lobes) and phase difference (from the tilt and shape) between the two signals. This method remains a standard tool for calibrating instruments, adjusting audio phase relationships in stereo systems, and diagnosing electronic circuits3. Bowditch curves (Lissajous figures) are the exact trajectories traced by a point subject to two perpendicular simple harmonic vibrations of different frequencies and phases, directly representing two-dimensional vibration modes in mechanical systems. Real-life applications include rotor dynamics and rotating machinery, where the Lissajous orbit displays frequency ratios, phase differences, and mode shapes to detect imbalances or faults4; composite vibrating screens, using Lissajous vibration synthesis to generate efficient screening trajectories5; and micro-vibration orbit control in flexible actuators and ultrasonic motors for precise motion6.

The classic equations can be generalized by adding a second sine term raised to a power, giving opportunity to create some curious figures, to which one can add fanciful names (Admiral Akbar, Angel, Bug, Capped egg, Capstan, DQ logo, Fly face, Heart, Leaf, Square weave, Star Trek, and others). These named presets are directly selectable in the accompanying AutoLISP implementation.

(defun C:BOWDITCH (/ basept xaxisangle cd sa sb sm om os divcount cosangle sinangle x0 y0 plineents segcount baseinfo paramstep

(setq id "Bowditch Curve"
      iq "x=a·sin(bt+c), y=d·sin(et+f)+g·[sin(ht+i)]ʲ"
      dcl "BOWDITCH"
      opt '("Admiral Akbar"
            "Angel"
            "Angled lemniscate"
            "Bifolium"
            "Bug"
            "Capped egg"
            "Capstan"
            "DQ logo"
            "Fly face"
            "Heart"
            "Leaf"
            "Lemniscate of Gerono"
            "New values"
            "Square weave"
            "Star Trek")
      kw 12
      mode 'polar
      dpr "# of divisions in curve"
      dct 360
      dpt nil
      span 360
      kw (ca id iq dcl opt kw mode dpr dct dpt span))
(cond
  ((eq kw 0) ; Admiral Akbar
   (setq fa 2.0 fb 1.0 fc 0.0 fd 1.0 fe 1.0 ff (/ pi 2) fg (/ 10.0 7) fh 1.5 fi (/ pi 2) fj 2.0))
  ((eq kw 1) ; Angel
   (setq fa 2.0 fb 1.0 fc 0.0 fd 1.0 fe 2.0 ff 0.0 fg 1.0 fh 1.5 fi (/ pi 4) fj 3.0))
  ((eq kw 2) ; Angled Lemniscate
   (setq fa 2.0 fb 1.0 fc 0.0 fd 1.0 fe 2.0 ff 0.0 fg 1.0 fh 0.5 fi (/ pi 4) fj 2.0))
  ((eq kw 3) ; Bifolium
   (setq fa 2.0 fb 1.0 fc 0.0 fd 1.0 fe 1.0 ff (/ pi 2) fg -2.0 fh 0.5 fi (/ pi 4) fj 1.0))
  ((eq kw 4) ; Bug
   (setq fa 1.0 fb 1.0 fc 0.0 fd 1.0 fe (/ 1.0 3) ff (/ pi 2) fg -1.0 fh 0.5 fi 0.0 fj 2.0))
  ((eq kw 5) ; Capped Egg
   (setq fa 1.0 fb 1.0 fc 0.0 fd 1.0 fe 1.0 ff (/ pi -2) fg 0.5 fh 0.5 fi (/ pi 2) fj 3.0))
  ((eq kw 6) ; Capstan
   (setq fa 1.0 fb 1.0 fc 0.0 fd 1.0 fe 1.0 ff (/ pi 2) fg -1.0 fh 1.5 fi (/ pi 2) fj 2.0))
  ((eq kw 7) ; DQ Logo
   (setq fa 1.0 fb 1.0 fc 0.0 fd 0.0 fe 1.0 ff 0.0 fg 0.5 fh 1.0 fi (/ pi 2) fj 3.0))
  ((eq kw 8) ; Fly Face
   (setq fa 2.0 fb 1.0 fc 0.0 fd 1.0 fe 1.0 ff (/ pi 2) fg -2.0 fh (/ 2.0 3) fi (/ pi 3) fj 1.0))
  ((eq kw 9) ; Heart
   (setq fa 1.0 fb 1.0 fc 0.0 fd 1.0 fe 1.0 ff (/ pi 2) fg -0.5 fh 1.5 fi (/ pi 4) fj 1.0))
  ((eq kw 10) ; Leaf
   (setq fa 1.0 fb 1.0 fc 0.0 fd 1.0 fe 1.0 ff 0.0 fg 0.5 fh 1.0 fi (/ pi 2) fj 3.0))

   (setq fa (get_real 2 "a (x-scale)" 1.0)
         fb (get_real 0 "b (x-frequency)" 6.0)

         fd (get_real 0 "d (y-scale)" 1.0)
         fe (get_real 0 "e (y-frequency)" 2.0)
         ff (* (get_real 0 "f (y-phase in °)" 0) (/ pi 180.0))
         fg (get_real 0 "g (y-second-term)" 0.0)
         fh (get_real 0 "h (y-second-frequency)" 0.0)
         fi (* (get_real 0 "i (y-second-phase in °)" 0) (/ pi 180.0))

  ((eq kw 13) ; Square Weave
   (setq fa 1.0 fb 1.0 fc 0.0 fd 1.0 fe 0.95 ff 0.0 fg 0.0 fh 0.0 fi 0.0 fj 0))
  ((eq kw 14) ; Star Trek
   (setq fa -2.0 fb 1.0 fc 0.0 fd -2.0 fe 1.0 ff (/ pi 3) fg -2.5 fh 1.0 fi 0.0 fj 2.0)))
(setq eq_display (strcat "\na=" (rtos fa 2 4) ", b=" (rtos fb 2 4) ", c=" (rtos (* fc (/ 180 pi)) 2 4) "°, d=" (rtos fd 2 4) ", e=" (rtos fe 2 4) ", f="
                         (rtos (* ff (/ 180 pi)) 2 4) "°, g=" (rtos fg 2 4) ", h=" (rtos fh 2 4) ", i=" (rtos (* fi (/ 180 pi)) 2 4) "°, j=" (rtos fj 2 4))
      xc '(* fa (sin (+ (* fb (eval a2)) fc)))
      yc '(+ (* fd (sin (+ (* fe (eval a2)) ff))) (* fg (alt_expt (sin (+ (* fh (eval a2)) fi)) fj nil)))
      skm '(T T T)
      a1 0
      a2 a1
