Pericycloid

A plane curve traced by a point on the circumference of a circle that rolls without slipping around a fixed base circle while containing it, mathematically the same as an epicycloid.

Pericycloid parametric equations:
\[ x=(R+r)\cos(t)-r\cos\Bigl(\dfrac{R+r}{r}t\Bigr),\quad y=(R+r)\sin(t)-r\sin\Bigl(\dfrac{R+r}{r}t\Bigr),\quad r=\dfrac{R}{n} \]

History and Applications

The pericycloid1 is a plane curve traced by a point on the circumference of a circle that rolls without slipping around a fixed base circle while containing it. The distinction between pericycloid and epicycloid lies only in the generation method; the resulting curve is mathematically equivalent to an epicycloid with adjusted radius ratio. See epicycloid entry.

In engineering, cycloidal curves including pericycloids are applied in the design of tooth profiles for cycloidal and planetary gear systems to achieve smooth meshing, efficient torque transmission, and reduced wear.

Pericycloid equation: \(x=(R+r)\cos(t)-r\cos(((R+r)/r)t),\ y=(R+r)\sin(t)-r\sin(((R+r)/r)t)\), where \(r=R/n\).

AutoLISP Code

(defun C:PERICYCLOID (/ basept xaxisangle cd sa sb sm om os divcount cosangle sinangle x0 y0 plineents segcount baseinfo paramstep
                        divpt xspan restartflag id iq dcl opt kw mode dpr dct dpt span eq_display xc yc skm a1 a2 x1 y1 x2 y2 fa fb)
  (setq id "Pericycloid"
        iq "x=(R+r)·cos(t)-r·cos(((R+r)/r)·t), y=(R+r)·sin(t)-r·sin(((R+r)/r)·t)"
        dcl nil
        opt nil
        kw nil
        mode 'polar
        dpr "# of divisions around circle"
        dct 360
        dpt nil
        span 360
        kw (ca id iq dcl opt kw mode dpr dct dpt span)
        fa (get_real 2 "R (base circle radius)" 1.0)
        fb (get_real 2 "n (# of cusps)" 3.0)
        eq_display (strcat "\nR=" (rtos fa 2 4) ", n=" (rtos fb 2 4))
        xc '(- (* (+ fa (/ fa fb)) (cos (eval a2))) (* (/ fa fb) (cos (* (1+ fb) (eval a2)))))
        yc '(- (* (+ fa (/ fa fb)) (sin (eval a2))) (* (/ fa fb) (sin (* (1+ fb) (eval a2)))))
        skm '(T T T)
        a1 0
        a2 a1
        x1 (eval xc)
        y1 (eval yc)
        a2 '(+ a1 paramstep)
        x2 '(eval xc)
        y2 '(eval yc))
  (cc))
