Conchal Curve

A circular quartic algebraic curve such that the product of the distance from points to a fixed point (−a, 0) and the distance to the fixed line x = a equals the constant c².

Conchal implicit equation:
\[ ((x - a)^2 + y^2)(x + a)^2 = c^4 \]
Conchal explicit equation:
\[ y = \pm \frac{\sqrt{(c^2 + a^2 - x^2)(c^2 - a^2 + x^2)}}{x + a} \]

History and Applications

The Conchal curve1, studied by German mathematician Oskar Schlömilch in 1878 and by G. Huber in 1895, takes its name from the Latin cochlea (snail or shell). It is the locus of points M for which the product of the distance from M to a fixed point F (−a, 0) and the distance from M to the fixed line x = a equals a constant c². This geometric definition produces a circular quartic algebraic curve whose shape varies with the relative sizes of the parameters a and c. When 0 < c < a the curve consists of two infinite branches asymptotic to the line x = −a together with a closed oval component. When c = a the curve is rational, the origin becomes a double point, and one branch includes a loop. When c > a the curve consists of two infinite branches with the same vertical asymptote x = −a.

No documented applications of the Conchal curve in engineering or the natural sciences were identified in standard mathematical references.

Due to portions of the curve on both sides of the x = −a asymptote, to obtain the full curve one must run the code three times according to the domain prompts (Right, Farleft, Nearleft).

References

AutoLISP Code

(defun C:CONCHAL (/ basept xaxisangle cd sa sb sm om os divcount cosangle sinangle x0 y0 plineents segcount baseinfo paramstep divpt restartflag
                    id iq dcl opt kw mode dpr dct dpt span eq_display xc yc skm a1 a2 x1 y1 x2 y2 fa fb fc fd fe ff maxdraw)
  (setq id "Conchal Curve"
        iq "y=±√((c²+a²−x²)(c²−a²+x²))/(x+a)"
        dcl nil
        opt nil
        kw nil
        mode 'param
        dpr "# of divisions in curve"
        dct 100
        dpt nil
        span nil
        kw (ca id iq dcl opt kw mode dpr dct dpt span)
        fa (get_real 2 "a (asymptote at x = −a)" 2.0)
        fb (get_real 2 "c (shell size parameter)" 2.0)
        kw (get_keyword 0 "Right Farleft Nearleft" "Right, Farleft, or Nearleft domain?: " "Right")
        eq_display (strcat "\na=" (rtos fa 2 4) ", c=" (rtos fb 2 4))
        fc (alt_expt (+ (* fa fa) (* fb fb)) 0.5 T)
        fd (if (> fa fb) (alt_expt (- (* fa fa) (* fb fb)) 0.5 T) 0.0)
        fe (cond ((and (< fb fa) (eq kw "Right")) fd) ((eq kw "Farleft") (- fc)) ((and (>= fb fa) (eq kw "Nearleft")) (- fa))
           ((and (< fb fa) (eq kw "Nearleft")) (- fa)) (T 0.0))
        ff (cond ((and (< fb fa) (eq kw "Right")) (- fc fd)) ((eq kw "Farleft") (- fc fa)) ((and (>= fb fa) (eq kw "Nearleft")) fa)
           ((and (< fb fa) (eq kw "Nearleft")) (- fa fd)) (T fc))
        maxdraw (get_real 2 "Maximum x and y values allowed?" 100)
        paramstep (/ ff divcount)
        xc '(+ fe (eval a2))
        yc '(/ (if (< (abs (setq fc (* (+ (* fb fb) (* fa fa) (- (* (setq fd (+ fe (eval a2))) fd))) (+ (* fb fb) (- (* fa fa)) (* fd fd))))) 1e-9)
            0.0 (alt_expt fc 0.5 T)) (avoid_zero (+ fd fa)))
        skm '(T nil T)
        a1 0
        a2 a1
        x1 (eval xc)
        y1 (eval yc)
        a2 '(+ a1 paramstep)
        x2 '(eval xc)
        y2 '(eval yc))
  (cc))
(C:CONCHAL)
