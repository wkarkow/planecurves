Knot Curve

A quartic plane algebraic curve with two parametric branches using nested radicals, shaped like an overhand knot.

Knot Curve implicit equation:
\[ (x^{2} - 1)^{2} = y^{2}(3 + 2y) \]
Knot Curve parametric equations:
\[ y = t,\quad x = \pm\sqrt{1 \pm t\sqrt{3 + 2t}} \]

History and Applications

The Knot Curve1,2, named by H. Martyn Cundy and A. P. Rollett, is a quartic plane curve (an algebraic curve whose defining equation is a polynomial of total degree 4 in the coordinates x and y). It appears as an illustrative example in their book Mathematical Models. The curve is defined implicitly by (x^{2} − 1)^{2} = y^{2}(3 + 2y). This equation produces a closed figure with a central region and two side regions, horizontal tangents at the x-intercepts (0,0) and (1,0), and vertical tangents at the y-intercepts (0,½) and (1,−1). The two mirrored branches plotted by the parametric code (with y = t and the combinations of signs inside the nested square roots) trace the entire curve exactly once over the chosen domain, providing a computationally efficient form for AutoCAD drafting without needing to solve the quartic algebraically at each step. The total area enclosed by the curve equals ⅙.

AutoLISP Code

(defun C:KNOT (/ basept xaxisangle cd sa sb sm om os divcount cosangle sinangle x0 y0 plineents segcount baseinfo
                   paramstep divpt xspan restartflag id iq dcl opt kw mode dpr dct dpt span eq_display xc yc skm a1 a2 x1 y1 x2 y2)
  (setq id "Knot Curve"
        iq ""
        dcl "KNOT"
        opt '("1st branch" "2nd branch")
        kw 0
        mode 'param
        dpr "# of divisions"
        dct 360
        dpt nil
        span nil
        kw (ca id iq dcl opt kw mode dpr dct dpt span))
  (cond
    ((eq kw 0)
     (setq xc  '(alt_expt (+ 1.0 (* (eval a2) (alt_expt (+ 3.0 (* 2.0 (eval a2))) 0.5 T))) 0.5 T)))
    ((eq kw 1)
     (setq xc  '(alt_expt (- 1.0 (* (eval a2) (alt_expt (+ 3.0 (* 2.0 (eval a2))) 0.5 T))) 0.5 T))))
  (setq eq_display "\nKnot curve: y(t)=t, x(t)=sqrt(1±t·sqrt(3+2t)"
        paramstep (/ 1.0 180.0)
        yc '(eval a2)
        skm '(nil T T)
        a1 -1.5
        a2 a1
        x1 (eval xc)
        y1 (eval yc)
        a2 '(+ a1 paramstep)
        x2 '(eval xc)
        y2 '(eval yc))
  (cc))
(C:KNOT)
