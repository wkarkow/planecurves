Alain's Curve

A plane algebraic curve proposed by Alain Juhel, morphing between crossed ovals, hyperbolas, and figure-eights depending on the b/a ratio.

Alain's Curve implicit equation:
\[ (x^{2} - y^{2})^{2} = a^{2} x^{2} - b^{2} y^{2} \]
Alain's Curve polar equation:
\[ r = \frac{\sqrt{a^{2} \cos^{2}(\theta) - b^{2} \sin^{2}(\theta)}}{|\cos(2\theta)|} \]

History and Applications

Alain's curve1 is a recent entry in MathCurve's catalog of plane algebraic curves, named after Alain Juhel of France, who proposed it for study. Juhel appears to be a contemporary enthusiast of mathematical curves rather than a historical figure like Bernoulli or Cassini, whose similar quartic curves (degree 4) date back to the 17th and 18th centuries. As with many modern algebraic discoveries, Alain's curve likely emerged from exploratory work with equations, highlighting how simple quadratic combinations can yield symmetric shapes without ties to classical problems like planetary motion or optics.

The curve always satisfies the origin as a point, since substituting x = 0, y = 0 gives 0 = 0, but polar conversions can obscure this unless boundary limits are considered, much like how derivatives approach slopes at points where functions touch zero. Depending on the ratio of parameters a and b, the curve morphs: for b = 0, it degenerates into a union of two hyperbolas; for 0 < b < a, it forms crossed ovals with cusps; for b = a, it becomes a hyperbola with its asymptotes; and for b > a > 0, it resembles a cylindrical lemniscate or figure-eight, pinched at the center. This versatility makes it a good teaching tool for understanding symmetry and domain restrictions through basic trigonometry, where angles determine valid real points, akin to how sine and cosine bound circles.

No real-life applications in engineering or natural sciences were found after searches across mathematical databases and literature. It serves primarily as an illustrative example in algebraic geometry.

AutoLISP Code

(defun C:ALAIN (/ basept xaxisangle cd sa sb sm om os divcount cosangle sinangle x0 y0 plineents segcount baseinfo paramstep
                  restartflag id iq dcl opt kw mode dpr dct dpt span eq_display xc yc skm a1 a2 x1 y1 x2 y2 fa fb fc fd rval)
  (setq id "Alain's Curve"
        iq "r=√(a²·cos²(θ)-b²·sin²(θ))/|cos(2θ)|"
        dcl nil
        opt nil
        kw 0
        mode 'polar
        dpr "# of divisions around circle"
        dct 360
        dpt nil
        span 360
        kw (ca id iq dcl opt kw mode dpr dct dpt span)
        fa (get_real 2 "a (scale)" 1.0)
        fb (get_real 0 "b (>a shape = horizontal 8)" 0.5)
        fc (get_keyword 0 "Real Imaginary" "Real or Imaginary values allowed?" "Real")
        eq_display (strcat "\na=" (rtos fa 2 4) ", b=" (rtos fb 2 4))
        fd '(- (* fa fa (cos (eval a2)) (cos (eval a2))) (* fb fb (sin (eval a2)) (sin (eval a2))))
        rval '(/ (alt_expt (if (eq fc "Imaginary") (abs (eval fd)) (max (eval fd) 0.0)) 0.5 nil) (avoid_zero (abs (cos (* 2.0 (eval a2))))))
        xc '(* (eval rval) (cos (eval a2)))
        yc '(* (eval rval) (sin (eval a2)))
        skm '(T T T T)
        a1 0
        a2 a1
        x1 (eval xc)
        y1 (eval yc)
        a2 '(+ a1 paramstep)
        x2 '(eval xc)
        y2 '(eval yc))
  (cc))
