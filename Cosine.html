Cosine Curve

Graph of y = a · cos(b x), the fundamental periodic function used to model simple harmonic motion.

Cosine Cartesian equation:
\[ y = a \cos (b x) \]

History and Applications

The cosine function1,2,3,4, one of the fundamental trigonometric functions, originated in ancient geometry through the study of chords in circles. In early Greek mathematics, particularly in the work of Claudius Ptolemy (c. 100–170 AD), trigonometric relationships were expressed using chord lengths. The transition to modern trigonometric functions occurred in Indian mathematics, where Aryabhata (476–550 AD) introduced the sine function (ardha-jya, “half-chord”), and its complementary counterpart, later called cosine (from complementi sinus). Islamic mathematicians Al-Battani (c. 858–929 AD) refined trigonometric tables and applied cosine in astronomical calculations, while Nasir al-Din al-Tusi (1201–1274) formalized plane and spherical trigonometry using sine and cosine as independent functions. These works were later translated into Latin, influencing Europeans such as Regiomontanus (1436–1476), who helped establish trigonometry as a distinct mathematical field. Isaac Newton contributed power series expansions, while Leonhard Euler provided the infinite series \( \cos x = \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n}}{(2n)!} \) and its connection to complex exponentials via Euler’s identity \( e^{ix} = cos(x) + i sin(x) \), unifying trigonometry, exponential growth, and oscillatory motion into a single framework.

The cosine function is central to modeling periodic and oscillatory phenomena5, describing simple harmonic motion of springs and pendulums, appearing in wave equations governing light, sound, and electromagnetic radiation, including interference and diffraction patterns, modeling AC circuits, where voltages and currents vary sinusoidally and phase relationships determine impedance and power transfer, describing vibration patterns in beams, plates, and mechanical systems. Cosine functions form the basis of Fourier series and transforms, allowing complex signals to be decomposed into sums of cosine and sine waves. This underlies modern signal processing, communications, image compression, and acoustics. In astronomy and navigation, cosine laws are essential in spherical trigonometry for determining distances and angles on celestial spheres and the Earth’s surface. The author used it extensively in medical ultrasound flow measurements. (defun C:COSINE (/ basept xaxisangle cd sa sb sm om os divcount cosangle sinangle x0 y0 plineents segcount baseinfo divpt xspan paramstep
                   restartflag id iq dcl opt kw mode dpr dct dpt span eq_display xc yc skm a1 a2 x1 y1 x2 y2 fa fb fc p1 p2)
  (setq id "Cosine Curve"
        iq "y=a·cos(b·x)"
        dcl "COSINE"
        opt '("origin,a,b values" "origin,half-wavelength, a" "origin,height,b value" "origin,height,h-wavelength" "origin,peak" "origin,trough"
              "peak,trough (new origin)" "origin,height,1 pt on curve" "origin,h-wave,1 pt on curve" "origin,height,wavelength")
        kw 0
        mode 'param
        dpr "# of divisions to division point"
        dct 200
        dpt '(2.0 0.0)
        span nil
        kw (ca id iq dcl opt kw mode dpr dct dpt span))
  (cond
   ((eq kw 0)
    (setq fa (get_real 2 "a (amplitude)" 1.0)
          fb (get_real 2 "b (frequency factor)" 1.0)
          fc (get_keyword 0 "Yes No" "Divide pi (half wavelength) by b" "Yes")
          fb (if (eq fc "Yes") (/ pi fb) fb)))
   ((eq kw 1)
    (setq fa (get_real 2 "a (amplitude)" 1.0)
          p1 (get_boundpt "Half-wavelength point" "Division point" divpt basept 0 nil T nil nil nil)
          fb (/ pi (get_xspan basept xaxisangle p1))))
   ((eq kw 2)
    (setq p1 (get_boundpt "Peak height point" "Division point" divpt basept nil nil nil 0 nil T)
          fa (get_yspan basept xaxisangle p1)
          fb (get_real 2 "b (frequency factor)" 1.0)
          fc (get_keyword 0 "Yes No" "Divide pi (half wavelength) by b" "Yes")
          fb (if (eq fc "Yes") (/ pi fb) fb)))
   ((eq kw 3)
    (setq p1 (get_boundpt "Peak height point" "Division point" divpt basept nil nil nil 0 nil T)
          p2 (get_boundpt "Half-wavelength point" "Division point" divpt basept 0 nil T nil nil nil)
          fa (get_yspan basept xaxisangle p1)
          fb (/ pi (get_xspan basept xaxisangle p2))))
   ((eq kw 4)
    (setq p1 (get_boundpt "Next peak point" "Division point" divpt basept nil nil nil 0 nil T)
          fa (get_yspan basept xaxisangle p1)
          fb (/ pi 0.5 (get_xspan basept xaxisangle p1))))
   ((eq kw 5)
    (setq p1 (get_boundpt "First trough point" "Division point" divpt basept nil nil nil 0 nil T)
          fa (- (get_yspan basept xaxisangle p1))
          fb (/ pi (get_xspan basept xaxisangle p1))))
   ((eq kw 6)
    (setq x1 0 x2 0)
    (while (or (= x1 x2) (= y1 y2))
      (setq p1 (get_point 0 "Pick new peak point (0 wave)" divpt basept)
            x1 (get_xspan basept xaxisangle p1)
            y1 (get_yspan basept xaxisangle p1)
            p2 (get_boundpt "Pick next trough point (1/4 wave)" "Division point" divpt basept x1 nil nil nil y1 nil)
            x2 (get_xspan basept xaxisangle p2)))
    (setq y2 (get_yspan basept xaxisangle p2)
          fa (/ (- y1 y2) 2)
          fb (/ pi (- x2 x1))
          y1 (- y1 fa)
          x0 (+ x0 (* x1 cosangle) (- (* y1 sinangle)))
          y0 (+ y0 (* y1 cosangle) (* x1 sinangle))))
   ((eq kw 7)
    (setq p1 (get_boundpt "Peak height point" "Division point" divpt basept nil nil nil 0 nil T)
          fa (get_yspan basept xaxisangle p1)
          p2 (get_boundpt "Point on curve" "Division point" divpt basept 0 nil T nil fa nil)
          x2 (get_xspan basept xaxisangle p2)
          y2 (get_yspan basept xaxisangle p2)
          fc (get_keyword 0 "A D" "Is point on Ascending or Descending slope" "A")
          fb (if (eq fc "A") (/ (- (* 2 pi) (acos (/ y2 fa))) x2) (/ (acos (/ y2 fa)) x2))))
   ((eq kw 8)
    (setq p1 (get_boundpt "Half-wavelength point" "Division point" divpt basept 0 nil T nil nil nil)
          x1 (get_xspan basept xaxisangle p1)
          fb (/ pi x1)
          x2 x1)
    (while (or (= x1 x2) (< (abs (cos (* fb x2))) 1e-4))
      (setq p2 (get_boundpt "Point on curve" "Division point" divpt basept 0 x1 T 0 nil T)
            x2 (get_xspan basept xaxisangle p2)
            fa (/ (get_yspan basept xaxisangle p2) (avoid_zero (cos (* fb x2)))))))
   ((eq kw 9)
    (setq p1 (get_boundpt "Peak height point" "Division point" divpt basept nil nil nil 0 nil T)
          p2 (get_boundpt "Wavelength point" "Division point" divpt basept 0 nil T nil nil nil)
          fa (get_yspan basept xaxisangle p1)
          fb (/ (* 2 pi) (get_xspan basept xaxisangle p2)))))
  (setq eq_display (strcat "\na=" (rtos fa 2 4) ", b=" (rtos fb 2 4))
        xc '(eval a2)
        yc '(* fa (cos (* fb (eval a2))))
        paramstep (/ xspan divcount)
        skm '(nil T T)
        a1 0
        a2 a1
        x1 (eval xc)
        y1 (eval yc)
        a2 '(+ a1 paramstep)
        x2 '(eval xc)
        y2 '(eval yc))
  (cc))
